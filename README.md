# Практическая работа №3
## Вариант 3: Поиск простых чисел

### Задание:
Пользователь вводит целое число N. Программа находит и выводит все простые числа в диапазоне от 2 до N, используя вложенные циклы for. Использует оператор break для оптимизации проверки на простоту.

### Реализованные возможности:

1. **Валидация ввода:**
   - Проверка на целое число
   - Проверка что N > 1
   - Обработка некорректного ввода

2. **Алгоритм поиска простых чисел:**
   - Внешний цикл for для перебора чисел от 2 до N
   - Внутренний цикл for для проверки делителей
   - Оптимизация: проверка делителей только до √number

3. **Использование оператора break:**
   - Немедленный выход из внутреннего цикла при нахождении делителя
   - Демонстрация оптимизации производительности

4. **Дополнительные функции:**
   - Подсчет количества найденных простых чисел
   - Форматированный вывод (10 чисел в строке)
   - Сравнение производительности с break и без break

### Ключевые аспекты управления потоком:

- **Циклы:** Вложенные циклы for для эффективного перебора
- **Условные операторы:** if для проверки условий
- **Операторы перехода:** break для оптимизации алгоритма
- **Обработка исключений:** try-catch для обработки ошибок

Ответы на контрольные вопросы:
1. В чем основное различие между операторами if-else и switch? В каких случаях предпочтительнее использовать каждый из них?

If-else используется для проверки логических условий и диапазонов значений, а switch - для сравнения с конкретными константными значениями. Switch предпочтительнее когда нужно проверить много конкретных значений, if-else - для сложных условий и диапазонов.

2. Объясните разницу между циклами while, do-while и for. Приведите примеры задач, где каждый из них наиболее уместен.

While: проверка условия перед выполнением (повтор ввода пока неверный)

Do-while: выполнение хотя бы один раз с проверкой после (игра "угадай число")

For: когда известно количество итераций (перебор массива, поиск простых чисел)

3. Для чего используются операторы break и continue? Как они влияют на выполнение циклов и оператора switch?

Break полностью прерывает выполнение цикла или switch, continue переходит к следующей итерации цикла. В данной работе break используется для оптимизации - выход при нахождении делителя.

4. Что такое исключение (exception) в .NET? Опишите структуру блока try-catch-finally и назначение каждой его секции.

Исключение - это ошибка времени выполнения. Try - код который может вызвать исключение, catch - обработка исключений, finally - код который выполняется всегда (освобождение ресурсов).

5. Как можно прервать выполнение бесконечного цикла?

С помощью оператора break, return, либо внешнего прерывания (Ctrl+C в консоли).

6. Что такое вложенные циклы и вложенные условные операторы? Какие особенности их использования нужно учитывать?

Это циклы/условия внутри других циклов/условий. Особенности: сложность отладки, влияние на производительность, правильное использование переменных-счетчиков.

7. Почему важно проверять ввод пользователя? Какие типы исключений чаще всего возникают при работе с консольным вводом?

Для предотвращения crashes и непредсказуемого поведения. Частые исключения: FormatException (неверный формат), OverflowException (число вне диапазона).
